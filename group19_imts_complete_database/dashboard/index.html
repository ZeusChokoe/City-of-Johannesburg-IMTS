Quick Setup How to Connect
1

🐬 MySQL Start XAMPP

Open XAMPP Control Panel → click START next to MySQL and Apache.
Then open http://localhost/phpmyadmin, go to Import, and run phase1_mysql/group19_schema.sql then phase2_mysql_logic/group19_logic.sql.

2

🍃 MongoDB Start the service

Windows: Run net start MongoDB in Command Prompt (Admin), or start from Services.
Then in a terminal: mongosh --file phase3_mongodb/group19_mongodb.js

3

🕸️ Neo4j Open Neo4j Desktop

Open Neo4j Desktop → click START on your database.
Open Neo4j Browser at http://localhost:7474 and paste Phase 4 Cypher sections in order.

4

⚡ Start the REST API

Open a terminal in phase5_api/:
npm install then copy .env.example .env (edit the Neo4j password) then node server.js
The API must be running for this dashboard to show live data.

5

🔄 Refresh this page

Once everything is running, click the ↻ Refresh button at the top right. All connection indicators should turn green.
